# Dark Dimensions

An English-first, localization-ready dark fantasy card RPG prototype.

## Development

```bash
npm install
npm run dev
```

Move on the world map with WASD or the arrow keys. Saving is enabled only
while the player is inside a city.

## Validation

```bash
npm test
npm run build
```

The original `cards.js` is retained as migration input and is not loaded by
the new application.
