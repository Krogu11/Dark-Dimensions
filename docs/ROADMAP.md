# Development Roadmap

Dark Dimensions is developed iteratively. This roadmap describes direction, not promised release dates.

## Current foundation

- [x] Seeded world generation
- [x] Free world travel and terrain rules
- [x] Tactical card battles and leader commands
- [x] Persistent Warband health and casualties
- [x] Tier-based unit XP and branching upgrades
- [x] Ironman autosaves and run-ending defeat
- [x] Character creation and starting backgrounds
- [x] Cities, markets, recruitment, healing, and contracts
- [x] Finite stocks, production, scarcity, and caravans
- [x] Factions, reputation, bounties, deliveries, and escorts
- [x] Equipment, consumables, food, wages, cargo, and morale
- [x] Content studio for cards, items, sprites, and terrain backgrounds

## Near-term work

- [ ] Refine Warband and prisoner management
- [ ] Expand city-specific recruitment identities
- [ ] Add clearer battle XP and reward breakdowns
- [ ] Improve unit effects, targeting identities, and combat feedback
- [ ] Expand item variety and meaningful economic decisions
- [ ] Balance survival pressure across short and long runs
- [ ] Improve responsive UI and accessibility
- [ ] Add automated visual regression coverage for major ledgers

## Campaign depth

- [ ] Lords who own and contest settlements
- [ ] Territory changes and faction wars
- [ ] Deeper reputation consequences and faction storylines
- [ ] Unique city events and regional problems
- [ ] Race unlock tracking between completed or failed runs
- [ ] More origins, upbringings, and turning points
- [ ] Named companions and authored personal events
- [ ] Run milestones, bosses, and final objectives

## World and content

- [ ] More terrain-specific encounters and battlefields
- [ ] Additional dungeons and dimensional anomalies
- [ ] Expanded kobold, orc, undead, elemental, beast, and machine trees
- [ ] Settlement visual variants
- [ ] Additional music and contextual ambience
- [ ] German localization after the English source text stabilizes

## Release preparation

- [ ] Save migration policy and compatibility tests
- [ ] Performance budgets for world generation and battle rendering
- [ ] Complete asset license inventory
- [ ] Settings, audio controls, key rebinding, and accessibility options
- [ ] Packaging and distribution decision
- [ ] Public contribution and issue templates
